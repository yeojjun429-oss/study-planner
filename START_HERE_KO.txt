1. ZIP 압축을 풀고 study_planner_v5_flask 폴더를 VS Code에서 여세요.
2. Terminal → New Terminal을 선택하세요.
3. 다음 명령어를 한 줄씩 입력하세요.

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py

4. Chrome 주소창에 http://127.0.0.1:5000 을 입력하세요.
5. 회원가입 → 설정(요일별 가능 시간) → 홈의 과목 관리 → 계획 순서로 진행하세요.
6. 설정에서 요일별 시간을 입력하고 과목별 세부 목표와 1~3순위를 정하세요. 계획 → 추천 플랜 보기 → 이 추천 플랜 추가하기를 누르세요.
7. 홈에서 타이머를 시작하고 공부가 끝나면 종료하고 저장하세요.
8. 진도 화면에서 실제 완료한 쪽수/문제 번호와 메모를 기록하세요.
9. 밀린 공부는 계획 화면의 미완료 공부 다시 배분으로 옮기세요.

자세한 설명과 테스트 방법은 README.md에 있습니다.
지금은 내 컴퓨터에서 실행하는 단계이며 인터넷에 공개된 상태가 아닙니다.
